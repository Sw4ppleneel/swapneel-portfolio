EXP—01

in production

Tulips.edu

Founder · Jun '26 — now · Ranchi · school ERP, live in 3 schools and used daily

Founded and built it alone, and I own the whole stack: architecture, deployment, operations, plus client onboarding, pricing, support and incident response. Multi-tenant school ERP: student records, fees (UPI deep links + QR), academics and parent communication across three surfaces — public site, staff ERP, parent portal — on one SPA. Tenant isolation is enforced in middleware with tenant_id on every table; every API route is role-checked across five roles; every state change emits an immutable audit event.

failure-mode thinking

The most frequent failure in an Indian school isn't the server — it's the teacher's connectivity. Attendance is offline-first: writes queue in IndexedDB and background-sync on recovery. Uploads go direct to R2 via presigned URLs, so storage failures never touch the app server. Migrations are raw versioned SQL, because schemas holding fee records don't get ORM surprises.

  • FastAPI · Python 3.11
  • PostgreSQL + asyncpg
  • Preact + TypeScript
  • Docker Compose
  • nginx
  • Cloudflare + R2

EXP—04

causal inference

University of Missouri

Research Assistant · May — Aug '26 · with Prof. Anuj Kapoor · Continuity of Care on Digital Health Platforms

A large-scale digital physiotherapy dataset. When a physiotherapist exits unexpectedly, it breaks a patient's care mid-episode. These provider-side shocks are plausibly exogenous — clean variation for asking how much continuity causally matters, and for whom.

My work spanned the identification strategy and the estimation pipeline, including pressure-testing parallel-trends assumptions across two difference-in-differences designs and validating dose-response gradients.

the hard part

The treatment is a path through an adaptive system, where standard regression breaks down.

identification
Staggered DiD (Callaway–Sant'Anna), provider exits as instruments, discrete-time hazard models.
causal ml
Double/debiased ML, causal forests, R-/DR-learners for heterogeneous effects across patient fragility.
sequence models
Transformer encoders over care trajectories, counterfactual RNNs, representation balancing (TARNet/CFRNet).

PRJ—01

open source · RAG

CitefyMe

local-first research RAG where every claim carries its evidence — and a verdict

Ask questions over papers pulled live from arXiv (abstracts, or whole papers via HTML/PDF ingestion). The pipeline retrieves with BM25, Gemini embeddings or hybrid RRF, extracts each claim from the answer, and runs it back against its cited passage for a supported / partial / unsupported verdict. Hand-rolled orchestration, no agent framework, with a FastAPI backend and a React + TypeScript UI that answer through the same code path the eval harness measures.

failure-mode thinking

Measured on real 20-paper arXiv corpora, not the toy set: that's where hybrid RRF turned out to lose to dense alone (MRR 0.79 vs 0.94), which the 4-paper set had hidden. The evals also caught retrieval making the system more confidently wrong on unanswerable questions — 100% citation coverage isn't knowing when to abstain — and that's written up as an open gap, not buried.

  • Python
  • BM25 · dense · RRF
  • Gemini embeddings
  • Claim verification
  • Recall@K · MRR evals
  • FastAPI
  • React + TS

PRJ—02

open source

SxQLear

database intelligence & archaeology tool

Born from a real problem: dropped into a 107-table production database with no documentation as a research assistant. SxQLear crawls and semantically maps unfamiliar SQL databases — a multi-signal inference engine (structural, lexical, statistical, semantic) proposes join relationships with confidence scores, and schema memory accumulates per project.

failure-mode thinking

Local-first by design: no cloud dependency, no data leaves the machine. Confidence scores instead of confident guesses — the tool says how sure it is, and asks a human before it believes itself.

PRJ—03

1st / 450+ teams

Asclepius

clinical intelligence engine · Hack-n-Win 3.0, CGC University · with Team Deranked

Multimodal pipeline for brain-tumour progression analysis: a Temporal Cognition Engine runs delta analysis across longitudinal MRI scans, and a RAG layer (MongoDB Atlas + Gemini 2.5 Flash) generates therapy reports. Ingestion is automated with multi-agent validation. Took first place out of 450+ teams — and second for best use of MongoDB.

failure-mode thinking

Built to fail soft: if the vector layer fails, the system falls back to preserved deterministic paths instead of returning nothing — in a medical context, silence is harm.
